# Operator: the Lens is the observatory; Memory is the database

## What was done
Recorded the operator's ruling in loom memory
(`decision-lens-is-the-observatory-memory-is-the-database-2026-11-09`) and closed roadmap item
`lens-meaning` with it as evidence.

## What was found / decided
- **Memory is the database**, at personal and shared scale.
- **The Lens is the observatory:** the interface layer plus the scripts and agents that observe
  the Memory and create fixes in projects by the rules set. It is adaptive, acting on the
  friction points the Memory records.
- This resolves Tapestry's "Lens = the interface" line: the observatory is the interface layer.
- **Raised for the operator:** lens-core holds the database standard (the spine). If Memory is
  the database, the standard may belong with Memory's shared-scale shape. Moving it would be a
  recategorization and needs a method evaluation.
